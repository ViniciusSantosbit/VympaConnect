# Escopo da etapa 01

Entregar fundação executável, organizada e documentada; sem lógica comercial. A fonte do pedido é o prompt fornecido nesta conversa.

Implementados: monorepo npm, web estrutural, API de health, persistência técnica, contratos compartilhados, qualidade, Docker e CI.
Planejados: Dashboard, Prospecção, CRM, Financeiro, Simulador Comercial, Operações Comerciais, Metas, Clientes, Contratos, IA e Administração.

Não implementados: autenticação/MFA/RBAC, cadastro de leads/clientes, operações de CRM/financeiro, cálculos de simulação, gráficos de metas, uploads, contratos operacionais, Maps/Places, Claude, email, filas, tempo real e pagamentos.

Não houve deploy nem publicação no GitHub. Workflow é um arquivo preparado; sua execução remota depende de o usuário publicar o repositório.
